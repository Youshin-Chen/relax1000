27 relax 1000 题 · 本地刷题
==========================

怎么打开
--------
解压后双击 index.html，用浏览器打开就能刷题。
不用装任何东西，也不用联网。建议用 Chrome 或 Edge。

题库内容
--------
数据结构 / 计算机组成原理 / 操作系统 / 计算机网络 四科，共 1576 道选择题，
按章节分组，每题都有答案和解析。

怎么用
------
- 首页点题库卡片进入，再选科目和章节开始做。
- 选完答案立刻判分，可以展开解析，也可以给这道题写笔记（支持公式）。
- 顶栏能进「错题本」和「笔记本」，随时回看做错的题和写过的笔记。
- 键盘：A–D 或 1–4 作答，N 或 → 下一题，P 或 ← 上一题。
- 右上角可以切换浅色 / 深色。

进度存在哪
----------
存在你自己浏览器里（localStorage），只在这台电脑上，不会上传。
所以：
- 一直用双击 index.html 的方式打开，进度就一直是同一份。
- 换浏览器、开无痕窗口、或者清浏览器数据，进度会从头开始。
- 想清空重来：进题库后点顶栏的「清空进度」，笔记会保留。

AI 讲解（可选）
--------------
页面里的「AI 讲解」需要你自己填接口地址、API Key 和模型（在 AI 讲解 → 设置里）。
不填的话不影响刷题，其他功能照常用。
Key 只存在你自己的浏览器里。
